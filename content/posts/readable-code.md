## 先说明问题

写清楚代码要处理什么输入、给出什么输出。一个具体例子通常比一句抽象定义更容易理解。

```javascript
function unique(values) {
  return [...new Set(values)];
}

unique(['a', 'b', 'a']); // ['a', 'b']
```

## 记下边界

上面的例子针对原始值去重。传入对象时，`Set` 比较的是对象引用。两个内容相同、引用不同的对象仍然会被保留。

```javascript
unique([{ id: 1 }, { id: 1 }]).length; // 2
```

## 留下选择的理由

如果需要按照对象的 `id` 去重，就应该先明确重复时保留哪一个值，再选择实现。
